# FixhSync — release

Installer di **FixhSync**, l'app Windows di Fixh IT per sincronizzare cartelle tra PC, server e NAS
(Locale, SMB, FTP/FTPS, SFTP), con servizio Windows e pianificazioni per job.

Questo repository contiene solo le versioni pubblicate: il codice sorgente è privato.

- **Scaricare**: dalla pagina [Releases](../../releases/latest), file `FixhSync-Setup-X.Y.Z.exe`.
- **Aggiornare**: da FixhSync 1.2.0 l'app controlla questo repository (Impostazioni → Controlla aggiornamenti)
  e installa le nuove versioni da sola, verificando l'impronta SHA256 del setup.
- Il setup si installa sopra la versione precedente mantenendo account e job.
